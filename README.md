# OpenCode agent-routing harness

Этот репозиторий содержит Python-маршрутизатор запросов и OpenCode-плагин. Маршрутизатор классифицирует задачу и формирует план маршрутизации — сам делегированный план он не выполняет.

## Запуск

Из корня репозитория:

```sh
python -m agent_router route --task "описание задачи"
python -m agent_router route --stdin
```

Для `--stdin` передайте текст задачи через стандартный ввод. Поддерживаются также параметры `--task-file`, `--project-root`, `--mode` и `--json`; подробности доступны через `python -m agent_router route --help`. Запуск требует Python и доступных проекту зависимостей; отдельные инструкции по установке здесь не предполагаются.

## Режимы и Jev

Режимы: `off`, `observe`, `assist`, `enforce`. По умолчанию — `observe`: классификация не меняет поведение агента. В `assist` применение плана ожидает подтверждения; `enforce` позволяет автоматически применить только безопасный маршрут `fast_readonly`, остальные требуют подтверждения.

Для обращения к внешнему Jev API требуется переменная окружения `TYPESAFE_API_KEY`. Доступность сервиса зависит от сети и учётных данных. Плагин `plugins/jev-router.js` предоставляет инструмент `jev_route`; его работа с реальной конфигурацией OpenCode и доступность сервиса здесь не проверялись.

## Роли и инструменты

Файлы `agent/` описывают роли `orchestrator`, `scout`, `researcher`, `test-analyst`, `implementer` и `reviewer`. Это определения возможностей, а не утверждение, что роли загружены в конкретном запуске. Оркестратор может делегировать через `task` и изучать файлы через `read`, `glob`, `grep`; изменять файлы может implementer через `edit`. `bash` допустим только если его явно разрешает политика текущей роли.

В репозитории нет конфигурации MCP-сервера; наличие MCP в окружении не проверялось. Здесь находятся определения ролей, а не bundled-файлы `SKILL.md`; пользовательские навыки не гарантированы каждому запуску.

## Тесты

```sh
python -m unittest discover -s agent_router/tests
```

Команда требует установленного Python и зависимостей, нужных тестам; отдельная подготовка окружения в этом README не описывается.
